# 💻 초보자를 위한 객체지향프로그래밍 스터디

연세대학교 YCC 2026-2학기 스터디

연세대학교 「객체지향프로그래밍」 수업을 수강하는 학우들을 위한 스터디입니다.
인강을 통해 C++ 기초 문법부터 클래스, 객체, 상속, 다형성 등
객체지향 프로그래밍의 주요 개념을 이해하고 직접 코드로 구현하는 것을 목표로 합니다.

컴퓨터과학과 부·복수전공자는 물론,
프로그래밍 경험이 전혀 없는 초보자도 환영합니다.

## 학습 자료
인프런 홍정모의 「따라하며 배우는 C++」 강의를 중심으로 진행합니다.
https://www.inflearn.com/course/following-c-plus?cid=198715

## 진행 방식
- 활동 유형: 스터디
- 진행 방식: 비대면 (Zoom)
- 진행 횟수: 주 1회
- 진행 시간: 참여자 일정 조율 후 결정
- 모집 인원: 10명 내외

개인별 학습 분량과 목표를 자유롭게 설정하여 학습합니다.
주차별 학습 내용을 바탕으로 궁금한 점과 어려웠던 부분을 함께 나누고,
시험 및 과제에 도움이 되는 정보를 공유합니다.
